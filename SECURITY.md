# Report a security problem privately

Use [GitHub's private vulnerability reporting](https://github.com/jessecmaddox3/converge-planner/security/advisories/new) for this repository. Do not put a vulnerability with working credentials, calendar data, response capabilities or personal information in a public issue.

Include an invented reproduction, the release version, the affected operating mode and the expected boundary. This is a personal project without a guaranteed response time. If your own installation is affected, protect its access and credentials while the report is investigated.

The local fictional mode is loopback-only. Hosted operators are responsible for their deployment, OAuth consent, service credentials, HTTPS, backups, scheduler and handling users' access/deletion requests. MIT licensing does not grant rights to someone else's calendar records or provider account.
