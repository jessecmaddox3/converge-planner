# Improve Converge

I built this for personal use and would be glad to see it become useful to someone else. Small fixes, clearer explanations, accessibility improvements and ideas for different ways to plan a trip are welcome.

Use invented examples in issues and pull requests. Never attach calendar exports, private response links, saved databases, screenshots with real names or provider credentials. For a vulnerability, use the private route in [SECURITY.md](SECURITY.md).

Explain what a user can do after your change, or show a small reproduction of the bug. Preserve the complete local demo and the distinction between public trip information and private contact/calendar data. Run the relevant checks from [DEVELOPMENT.md](docs/DEVELOPMENT.md). Add a regression that demonstrates behavior when changing logic; copy and styling edits do not need tests that just repeat the text.

By contributing, you agree your changes may be distributed under this project's MIT license. Retain upstream notices for anything you add. Suggested areas: calendar-provider adapters, internationalization, large-group accessibility and clearer travel-conflict explanations.
